AU TSM Progressive Creator V5.1

Fix:
The manual creator was progressively revealing Body Type and Role, but an older
desktop grid rule still reserved only 620px for the creator row. This caused
Character Progression and the Official Roster to overlap the newly revealed steps.

V5.1:
- Manual creator row now expands automatically with revealed steps.
- Character Progression always starts below the complete creator.
- Recent Character Applications stretches beside the creator and remains scrollable.
- Wheel mode keeps its intended fixed 620px layout.
- Official Roster is forced to remain below the creator/progression content.

No Supabase changes are required.
